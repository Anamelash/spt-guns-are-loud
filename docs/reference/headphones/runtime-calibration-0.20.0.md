# Перенос справочника в расчёты — 0.20.0

Выбор данных хранится в `calculation-selection.json`. `build_runtime_profiles.py` извлекает точные числовые ряды из записей исследования и генерирует рабочие профили; `--check` проверяет отсутствие расхождений. Исследовательские файлы не переписываются. Эта явная калибровка дополняет исходный индекс `reference.json`, где автоматическое применение сырых записей по-прежнему запрещено.

ComTac II, Sordin и CENS сохраняют уже подключённые документальные кривые. Для Sordin остаётся перенос современной серии на MSA, для CENS — семейства на DX5. Для RAC, XCEL, Liberator и ГСШ нет применимой подтверждённой частотной таблицы: сохраняются оценки. Обычный M32 не получает характеристики M32 Plus. Четыре AMP сохраняют явно запрошенный fallback на RAC, хотя отдельная таблица AMP имеется в справочнике.

Рабочие профили обновлены сразу для всех цветовых алиасов. Серверные шаблоны, масса, цена и ванильные настройки компрессора не изменяются; Realistic DSP и клиентское окно осмотра читают один профиль.

## Расчёт

Полные исходные mean-ряды определяют цели пассивного фильтра. SD и APV сохраняются отдельно, отсутствующие значения представлены NaN, не нулём; их не вычитаем повторно из mean. Некорректные и несортированные точки отвергаются при создании профиля. Три средние полосы служат только для интерфейса.

Нативный подбор фильтров получил повторный поиск с другой начальной шириной при попадании в локальный минимум. Изменение необходимо для Razor при 32 кГц. Допуск публикации остался 1,5 дБ, пределы управляющих параметров не расширены. Фаза и отклик между точками остаются модельной реконструкцией; совпадение опорных частот не доказывает точную физическую АЧХ.

Опубликованные NRR/SNR, уровни dB(A), характеристики динамика и время активации другой ревизии не подменяют неизвестные gain/attack/hold/release. Электронная модель остаётся приближённой. Дополнительные реальные характеристики сохраняются в справочнике; они не становятся несуществующими игровыми функциями питания, связи или ANC.

## Проверка

346 тестов: все 14 профилей при 32/44,1/48 кГц, независимое вычисление ошибки нативного каскада, публикация кеша, соответствие выбранным источникам, алиасы, неизвестный SD, отдельный APV, валидация входных массивов. Генератор проверен с `--check`.

Живая проверка пока не выполнена. После запуска сравнить одни и те же выстрелы и окружение в Vanilla/Realistic для ComTac V/VI, IV, TEP и Razor, включая первый выстрел и очередь. Проверить применение профиля без fallback, отсутствие щелчков при смене наушников и отображение трёх полос. Тесты и установка не являются подтверждением звучания в рейде.
