# Справочник реальных характеристик наушников

Дата исследования: 7 сентября 2026 года. Назначение — исходные данные для последующих расчётов Guns Are Loud. Это справочник, а не новая звуковая калибровка: действующие профили, игровой код и установленная сборка в рамках исследования не менялись.

- [Общий индекс для расчётов](reference.json): все игровые идентификаторы, ссылки на записи и правила допуска данных. [Снимок игровых свойств](inventory.json) хранится отдельно: эти значения не выдаются за характеристики реальных изделий.

Перечень собран из базы `D:\Games\SPT_4.1.3\SPT_Runtime\SPT_Data\database\templates\items.json` и определений CustomItems установленных модов с разрешением наследования. Все просмотренные JSON разобраны без ошибок. Лог `user/logs/spt/spt20260907.log` подтверждает загрузку Epic’s All In One 5.0.1 и WTT-ContentBackport 2.0.1. Это статический перечень предметов установленных модов, не выгрузка окончательной базы работающего сервера и не каталог всех существующих модов SPT.

Исследование выполнили три Luna-агента с последующей проверкой источников и спорных соответствий. Неизвестные значения оставлены неизвестными; формулировка «не найдено» означает результат этого поиска, а не доказательство отсутствия документа вообще.

## Какие данные сохраняем

Все найденные полезные ТТХ: частотные таблицы среднего ослабления, разброса и APV; SNR/NRR/H/M/L; характеристики микрофонов, динамиков, электронного пропускания окружающих звуков, режимы, усиление, ограничения уровня, опубликованные временные характеристики; внешние аудиоинтерфейсы и связь; питание, автономность, масса, крепления, амбушюры/насадки, материалы, эксплуатационная среда, IP и стандарты. Наличие раздела не означает, что все его параметры опубликованы для каждого изделия.

Для каждого числа важны единицы, модель/ревизия, конфигурация, метод испытания и источник. Характеристика динамика не является АЧХ всего электронного тракта. Заявленное время срабатывания не заменяет одновременно атаку, удержание и восстановление. Время запуска устройства не является задержкой проходящего звука.

## Правила использования в расчётах

1. **Выбор изделия.** Сначала TemplateId → физическая модель → ревизия → крепление → амбушюры/насадка → режим. Цвет сам по себе не доказывает другую акустику, но совпадение цвета не доказывает совпадение ревизии. Не объединять RAC с AMP, ComTac IV с чашечными ComTac, Razor Slim с Digital, обычный M32 с Plus/Mark4.
2. **Пассивная защита.** Хранить исходные частотные точки без подмены. Среднее ослабление, SD и APV — отдельные ряды. APV может отличаться от вычитания округлённых опубликованных MV и SD; это не основание переписывать таблицу. ANSI и EN измерения не усреднять между собой.
3. **Переход к фильтру.** Лабораторная защитная кривая может служить целевой оценкой пассивного тракта после выбора конфигурации, но не задаёт фазу, посадку или точную передаточную функцию уха. Интерполяция, поведение вне измеренного диапазона и допуски оформляются отдельно как модельные предположения. SNR/NRR не превращать в постоянное вычитание из всех частот.
4. **Электроника.** Не смешивать выходной уровень dB(A), входной criterion level, порог ограничения, усиление dB и цифровой уровень dBFS. Для переноса физических уровней в DSP нужна отдельная калибровка игровых сигналов. При неизвестной компрессионной кривой не выводить её из одного «82 дБ».
5. **Двойная защита.** Показатели гарнитуры с NFMI-вкладышами или обычными берушами принадлежат комбинации. Не складывать рейтинги и не применять их к предмету, изображающему только гарнитуру.
6. **Достоверность.** Данные исходного руководства, даже если оно размещено у дилера, отделять от пересказа продавца. Отдельно хранить подтверждённость источника и соответствие игровому предмету: официальный документ соседней модели остаётся переносом данных. Противоречивые и явно шаблонные страницы сохранять как спорные сведения, не как расчётные константы.
7. **Неизвестное не равно нулю.** Отсутствующее значение — `null`/unknown. Временные предположения текущей модели (например, общая электроника) не становятся реальными ТТХ после включения в справочник.
8. **Расчётный профиль — отдельный результат.** Ни одна запись справочника не применяется автоматически. При выпуске калибровки нужно явно выбрать набор данных, записать переносы/предположения и проверить DSP. Для Inspection перенос с семейства, неизвестная посадка и предложенные параметры должны сохранять отметку `*`.

Отдельно проверять H/M/L/SNR: некоторые таблицы дают для этих показателей собственные строки MV, SD и APV. Средний SNRm не следует выдавать за итоговый рейтинг SNR. В M32 Plus опубликованный APV на 8 кГц расходится с вычитанием напечатанных mean/SD на 0,4 дБ; значение сохранено как в источнике и отмечено для проверки. Незаполненные SD ComTac V и последняя SD Razor Digital BT явно обозначены: извлечение доступных копий не позволило надёжно подтвердить их, числа не угадывались.

## Приоритет дальнейшей калибровки

Сначала заменить общие предложенные пассивные кривые там, где найден подходящий документ и можно установить вариант насадки/крепления. С версии 0.19.2 четыре модовых AMP временно используют профиль FAST RAC по запросу пользователя; отдельная калибровка AMP остаётся дальнейшей задачей. Сохранить различие MSA Sordin из игры и современной серии SordinHEAR2, а также региональных документов PELTOR. Электронные параметры менять только в пределах реально опубликованных данных; недостающие усиление по режимам, attack/hold/release и задержку нельзя достоверно восстановить из рейтинга защиты.

Сборка/тесты здесь не запускались: меняется справочная документация. Числовая согласованность файлов проверяется отдельно от правильности будущего звука; окончательное принятие звуковой калибровки требует сравнения в рейде.
