# Тактические гарнитуры: справочная проверка характеристик

Дата проверки: 2026-09-07. Это исследование реальных изделий, а не перенос игровых коэффициентов. Числа ниже оставлены только при наличии прямого источника; если источник не публикует параметр, это отмечено как неизвестно. NRR/SNR/H-M-L — итоговые рейтинги лабораторной защиты, а не частотная АЧХ. Criterion level — уровень критерия для испытания level-dependent системы, а не универсальный порог «слышимости».

## Ограничения для игровых расчётов

Производительские attenuation tables измеряют конкретную посадку, уплотнение, испытательный стандарт и конфигурацию (headband/helmet, PVC/gel, NFMI вкладыши). Их нельзя безоговорочно переносить на внутриигровой «headset multiplier». Для реконструкции физики нужны отдельные параметры: частотная passive curve, active limiter curve, ambient gain/profile, latency и режимный переход. Для Sordin опубликованное 82 dB(A) sound-limit/compression value, для ГСШ 115 dB и для Safariland 4–9 dB в Move mode следует хранить отдельными полями с семантикой источника, а не смешивать с NRR.
